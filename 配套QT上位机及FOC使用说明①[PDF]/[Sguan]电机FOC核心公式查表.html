▾1符号速查表先分清电感与磁链，再往下看公式

电感：Ld / Lq / Ls / L0 / ΔL 的区分

表贴式 SPMSM：气隙均匀，Ld = Lq ≜ Ls（同步电感，一个值即可）
内嵌式 IPMSM：Ld ≠ Lq（一般 Ld < Lq）。αβ 静止坐标系一般式中没有单一 Ls，改用：
　平均电感 L0 = (Ld + Lq)/2　差模电感 ΔL = (Ld − Lq)/2（产生 2θe 项；SPMSM 时 ΔL = 0，一般式退化为 SPMSM 式）
电流环整定：d 轴取 Ld，q 轴取 Lq；SMO（表贴式）中用 Ls。

磁链：ψf / ψd / ψq / ψs / ψαβ / ψrαβ 的区分

ψf：永磁体磁链（转子磁场幅值，常数，单位 Wb）
ψd = Ld·id + ψf、ψq = Lq·iq：定子磁链 dq 分量（注意 ψd 里含 ψf）
ψs = √(ψd² + ψq²)：定子磁链幅值
ψα / ψβ：定子磁链 αβ 分量（磁链观测器电压模型的输出）
ψrα = ψα − Ls·iα、ψrβ = ψβ − Ls·iβ：转子磁链 αβ 分量（≈ ψf·cosθe / ψf·sinθe，用于提取 θ̂e）

▾2PMSM 三大方程（dq 旋转坐标系）电压 · 磁链 · 转矩 · 机械

2.1 电压方程

ud = Rs·id + Ld·diddt − ωe·Lq·iq
uq = Rs·iq + Lq·diqdt + ωe·(Ld·id + ψf)
uduq = Rsidiq + Ld00Lqddtidiq + ωe−Lq·iqLd·id + ψf
第三项为旋转电动势（反电动势 + 耦合项）：−ωeLqiq 是 q 轴电流在 d 轴产生的耦合电压，ωe(Ldid+ψf) 含永磁体反电动势 ωeψf。FOC 前馈解耦即补偿这两项。

2.2 磁链方程

ψd = Ld·id + ψf　　ψq = Lq·iq　　ψs = √ψd2 + ψq2

2.3 转矩方程

Te = 32·p·[ ψf·iq + (Ld − Lq)·id·iq ]　（IPMSM 通式，也写作 Te = 32·p·(ψd·iq − ψq·id)）
SPMSM（Ld = Lq）：　Te = 32·p·ψf·iq
第一项 (3/2)·p·ψf·iq 为永磁转矩，第二项为磁阻转矩（IPMSM 特有，Ld < Lq 时给负的 id 可增转矩 → MTPA）。

2.4 机械运动方程

J·dωmdt = Te − TL − B·ωm
ωe = p·ωm　　dθedt = ωe
以上 dq 方程用电角速度 ωe 表示；部分文献用机械角速度 ωm 表示 dq 方程（此时系数中会多出 p），推导时注意统一约定。

▾3静止 αβ 坐标系方程SMO / 磁链观测器都在这个坐标系里做

3.1 SPMSM αβ 电压方程（观测器常用式）

uα = Rs·iα + Ls·diαdt + eα　　uβ = Rs·iβ + Ls·diβdt + eβ
eα = −ωe·ψf·sin θe　　eβ = +ωe·ψf·cos θe
uαuβ = Rsiαiβ + Lsddtiαiβ + eαeβ
反电动势 eα/eβ 里藏着转子位置与速度——SMO 正是把它当作扰动观测出来。

3.2 反电动势与转子位置 / 速度的关系

θe = atan2( −eα, eβ ) = −atan2( eα, eβ )　　ωe = √eα2 + eβ2ψf

3.3 IPMSM αβ 一般式（进阶，含 2θe 项）

ψα = L0·iα + ΔL·( iα·cos 2θe + iβ·sin 2θe ) + ψf·cos θe
ψβ = L0·iβ + ΔL·( iα·sin 2θe − iβ·cos 2θe ) + ψf·sin θe
uα = Rs·iα + dψαdt　　uβ = Rs·iβ + dψβdt　　L0 = Ld+Lq2，ΔL = Ld−Lq2
ΔL = 0 时上式退化为 3.1 的 SPMSM 式。IPMSM 上 SMO 若仍用 3.1 的简化模型，会引入 2θe 谐波误差——工程上凸极率不大时常用近似 + 补偿，精确观测需用一般式或 dq 系观测器。

▾4坐标变换矩阵Clarke · Park · 反变换

4.1 Clarke 变换（abc → αβ，等幅值）

iαiβ = 231−1/2−1/20√3/2−√3/2iaibic
iα = 23( ia − 12ib − 12ic )　　iβ = √33( ib − ic )　　（ia+ib+ic=0 时：iα = ia）

4.2 Clarke 逆变换（αβ → abc，等幅值）

iaibic = 10−1/2√3/2−1/2−√3/2iαiβ

4.3 Park 变换（αβ → dq）

idiq = cos θesin θe−sin θecos θeiαiβ

4.4 Park 逆变换（dq → αβ，FOC 输出用）

uαuβ = cos θe−sin θesin θecos θeuduq
以上均为等幅值变换（系数 2/3，变换前后相电流幅值不变）——FOC 控制代码中最常用。另有等功率变换（系数 √(2/3)，功率守恒，转矩公式中 3/2 系数会消失）。两套体系混用会差 √(2/3) 倍，工程文档务必统一。

▾5滑模观测器 SMO（静止坐标系经典式）无位置传感器 · 表贴式 SPMSM

5.1 电流观测器方程

diαdt = −RsLs·iα + 1Ls·( uα − vα )　　diβdt = −RsLs·iβ + 1Ls·( uβ − vβ )
ddtiαiβ = −RsLsiαiβ + 1Lsuα − vαuβ − vβ

5.2 滑模控制函数（三种形式，选其一）

符号函数：　v = k·sign( i )，即 vα = k·sign( iα − iα )，vβ = k·sign( iβ − iβ )
饱和函数（抑抖振）：　v = k·sat( i / δ )，sat(x) = x（|x| ≤ 1），sign(x)（|x| > 1）
Sigmoid 连续化：　v = k·[ 21 + e−a·i − 1 ]　　（a 越大越接近 sign，越平滑抖振越小但滞后越大）

5.3 电流误差状态方程（滑动模态分析用）

diαdt = −RsLs·iα + 1Ls·( eα − vα )　　diβdt = −RsLs·iβ + 1Ls·( eβ − vβ )

5.4 等效控制提取：低通滤波得到反电动势

zα = ωcs + ωc·vα　　zβ = ωcs + ωc·vβ　　（时域：dzdt = ωc·( v − z )）
滑动模态建立后：　zα ≈ eα = −ωe·ψf·sin θe　　zβ ≈ eβ = +ωe·ψf·cos θe

5.5 转子位置与速度估计

θe = −atan2( zα, zβ ) = atan2( −zα, zβ )　　ωe = dθedt（工程上再经 LPF 或 PLL）
低通滤波相位补偿：　θe,c = θe + Δθ，　Δθ = arctan( ωe / ωc )

5.6 稳定性条件（Lyapunov 可达性）

V = 12( iα2 + iβ2 )　⇒　V < 0　当　k > max( |eα|, |eβ| ) = ωe·ψf
工程取值：k ≥ ωe,max·ψf（最大电角速度对应反电动势幅值）并留 1.2~1.5 倍裕量；k 过大会加剧抖振，配合 sat/sigmoid 与合理 ωc（一般取 ωc ≥ 2~4 倍 ωe,max，兼顾滤波滞后）。
符号约定提醒：部分教材定义 v = −k·sign(i)（观测器方程中对应加号），与本文相反——使用前请与所引文献核对加减号，否则位置会差 π。

▾6磁链观测器电压模型 · 电流模型 · Gopinath 混合型

6.1 电压模型（纯积分）

ψα = ∫( uα − Rs·iα ) dt　　ψβ = ∫( uβ − Rs·iβ ) dt
问题：纯积分对初始值、直流偏置、采样漂移敏感（输出漂移 / 饱和）。工程替代：一阶低通近似积分 ψ = (u − Rs·i)/(s + ωc)，ωc 取比最低运行频率更低的截止值（如额定电频率的 1/10），高速时近似积分。

6.2 电流模型（需要转子位置，SPMSM）

ψα = Ls·iα + ψf·cos θe　　ψβ = Ls·iβ + ψf·sin θe

6.3 转子磁链提取与位置估计

ψrα = ψα − Ls·iα ≈ ψf·cos θe　　ψrβ = ψβ − Ls·iβ ≈ ψf·sin θe
θe = atan2( ψrβ, ψrα )　　ωe = dθedt

6.4 Gopinath 混合型（电压模型 + PI 校正到电流模型）

dψαdt = uα − Rs·iα + Kp·( ψα,c − ψα ) + Ki·∫( ψα,c − ψα ) dt
dψβdt = uβ − Rs·iβ + Kp·( ψβ,c − ψβ ) + Ki·∫( ψβ,c − ψβ ) dt
s 域：　ψ = 1s·[ u − Rs·i + G(s)·( ψc − ψ ) ]，　G(s) = Kp + Kis
电流模型给定（用估计位置）：　ψα,c = Ls·iα + ψf·cos θe　　ψβ,c = Ls·iβ + ψf·sin θe
原理：稳态时 PI 校正迫使 ψ → ψc（低速准），动态时电压模型主导（高速准）——取两者之长。位置提取仍用 6.3 式（θ̂e = atan2(ψ̂β − Lsiβ, ψ̂α − Lsiα)）。

6.5 SMO 与磁链观测器对比（选型参考）

特性滑模观测器 SMO磁链观测器（电压/混合型）
实现难度结构简单，计算量小混合型稍复杂（含 PI / 低通）
参数依赖仅 Rs、Ls，鲁棒性强电压模型仅 Rs；电流模型需 Ls、ψf、θe
中高速好（需补偿滤波相位滞后）好（电压模型主导）
低速 / 零速差（反电动势小，滤波滞后大）混合型靠电流模型，低速好
固有缺陷抖振（用 sat / sigmoid 抑制）积分漂移（用低通替代 / PI 校正）
适用风机、水泵、压缩机等中高速无感宽速域无感，低速带载启动

▾7高频注入法 HFI（估计同步系 γδ）低速 / 零速无感 · IPMSM 凸极性

7.1 原理与适用

利用 IPMSM 的凸极性（Lq ≠ Ld）：向估计 d 轴（γ 轴）注入高频电压，δ 轴高频电流响应中携带位置误差 θ = θe − θe 的信息，解调后由 PLL 跟踪使误差收敛。 适用于低速 / 零速无感启动（该区间反电动势法失效），常与 SMO 组合成全速域方案：低速 HFI → 中高速切换 SMO。 前提是电机有凸极——表贴式 SPMSM（Ld = Lq）经典 HFI 不适用（可借助饱和凸极或 αβ 系旋转注入等变体）。

7.2 估计同步系 γδ 与高频模型

xdxq = R(θ)·xγxδ，　R(θ) = cosθ−sinθsinθcosθ，　θ = θe − θe（位置误差）
高频模型（ωh ≫ ωe，忽略 Rs 与反电动势）：　udh ≈ Ld·didhdt　　uqh ≈ Lq·diqhdt

7.3 高频电压注入（旋转正弦注入）

uγh = Uh·cos( ωh·t )　　uδh = 0　　（叠加在 FOC 输出电压上：uγ* = uγ,PI + uγh）

7.4 高频电流响应（γδ 系）

iγh = Uhωh·sin(ωh·t)·[ cos²θLd + sin²θLq ]
iδh = Uh2·ωh·( 1Lq − 1Ld )·sin( 2θ )·sin(ωh·t) = Uh·( Ld − Lq )2·ωh·Ld·Lq·sin( 2θ )·sin(ωh·t)
δ 轴高频电流幅值 ∝ (1/Lq − 1/Ld)·sin(2θ)——凸极越强、误差信号越大；θ̃ = 0 时 iδh = 0。

7.5 解调：乘法检波 + 低通滤波（外差法）

ε = LPF[ iδh·sin( ωh·t ) ] = Uh4·ωh·( 1Lq − 1Ld )·sin( 2θ ) ∝ sin( 2θ )
流程：相电流采样 → Clarke → Park(θ̂e) → BPF（带通 ωh，滤基波）→ 取 δ 轴分量 × sin(ωht) → LPF → 误差 ε。
方波注入变体：uγh 每控制周期在 ±Uh 间翻转（方波注入），用相邻周期电流差分直接解调，无需 BPF/LPF，动态更高、实现更简单，但注入频率受 PWM 周期约束。

7.6 位置 / 速度跟踪（PLL）

ωe = Kp·ε + Ki·∫ ε dt　　θe = ∫ ωe dt　　（闭环使 θ → 0 或 π）
PLL 带宽取速度环带宽的 5~10 倍（远低于 ωh）。符号约定提醒：ε 的符号随 θ̃ 定义、解调参考（sin/cos）而异，整定前必须验证误差符号，否则收敛到错误平衡点。

7.7 初始位置与磁极极性辨识

误差信号只含 sin(2θ̃)，θ̃ = 0 与 θ̃ = π 均为稳定点 → 分两步：
① 初始角度辨识：静止时注入 HF 信号，PLL 收敛得 θ̂0（存在 0 / π 歧义）；
② 极性辨识：沿 θ̂0 方向注入正、负 d 轴电压脉冲，利用 d 轴磁路饱和——与 ψf 同向的脉冲电流响应幅值更大——判断转子磁极真实方向；若相反则 θ̂e 修正 +π。

7.8 注入参数选取经验

频率 ωh：一般 0.5 ~ 2 kHz（约 fsw 的 1/10 ~ 1/5）；需远高于基波频率、远低于电流环带宽，并避开机械谐振与噪声敏感区；
幅值 Uh：工程上约取额定电压的 5% ~ 10%，校核高频电流纹波（约额定电流 5% ~ 10%）与可闻噪声、附加损耗；
解调 LPF 截止：远低于 2ωh，高于 PLL 带宽；
交叉饱和：带载后凸极轴线发生偏移，位置误差增大，可离线标定误差补偿表。

▾8FOC 闭环控制结构解耦 · 双环 · SVPWM · 极限约束

7.1 电流环：PI + 前馈解耦

ud* = Kp,d·( id* − id ) + Ki,d·∫( id* − id ) dt − ωe·Lq·iq
uq* = Kp,q·( iq* − iq ) + Ki,q·∫( iq* − iq ) dt + ωe·( Ld·id + ψf )
末项为前馈解耦 / 反电动势补偿（对应 2.1 旋转电动势项），可提高动态解耦性能；不加前馈、仅靠 PI 也可稳定，但高速耦合明显。

7.2 双环结构

速度环（外环）：ωm* − ωm → PI → iq*　；id* 由 MTPA / 弱磁策略给定（SPMSM 常用 id* = 0）
电流环（内环）：id,q* − id,q → PI + 解耦 → ud,q* → 反 Park → uα,β → SVPWM → 三相逆变器 → PMSM
反馈支路：三相电流采样 → Clarke / Park → id,q；位置与速度来自编码器或观测器（无感 FOC：低速 HFI、中高速 SMO / 磁链观测器，见 ⑤⑥⑦）

7.3 SVPWM 公式集（七段式）

定义：　X = √3·Ts·uβUdc　　Y = ( 3uα + √3·uβ )·Ts2·Udc　　Z = ( −3uα + √3·uβ )·Ts2·Udc
扇区判定：　A = ( uβ > 0 )　B = ( √3·uα − uβ > 0 )　C = ( −√3·uα − uβ > 0 )　N = A + 2B + 4C
扇区映射：　N = 3 → Ⅰ，N = 1 → Ⅱ，N = 5 → Ⅲ，N = 4 → Ⅳ，N = 6 → Ⅴ，N = 2 → Ⅵ
扇区ⅠⅡⅢⅣⅤⅥ
T1−ZZX−X−YY
T2XY−YZ−Z−X
过调制处理：　若 T1 + T2 > Ts，则 T1 = T1·TsT1+T2，T2 = T2·TsT1+T2；T0 = Ts − T1 − T2
线性调制区最大相电压幅值 = Udc/√3（电压利用率较 SPWM 提升约 15.5%）。不同教材对 X/Y/Z 的定义与作用时间映射写法略有差异，实现前请与所选教材/源码核对。

7.4 电流 / 电压极限约束

电流极限圆：　id2 + iq2 ≤ is,max2（受逆变器 / 电机热约束）
电压极限椭圆：　( Ld·id + ψf )2 + ( Lq·iq )2 ≤ ( us,max / ωe )2，us,max = Udc/√3
转速升高 → 电压椭圆收缩 → 进入弱磁区：id* 向负方向调整以满足椭圆约束（弱磁），配合 MTPA（低速）/ MTPV（深弱磁）策略给定 id*。

▾9参数整定 + 计算器电流环 · 速度环 · MTPA

8.1 电流环 PI（带宽法 / 零极点对消）

ωc = 2π·fc　　Kp = L·ωc　　Ki = Rs·ωc　　（d 轴取 Ld，q 轴取 Lq）
PI 零点 −Rs/L 对消电机极点，闭环近似一阶惯性 ωc/(s+ωc)。工程取 fc ≈ fsw/10 ~ fsw/20（fsw 为开关频率）；Kp 单位 V/A（Ω），Ki 单位 V/(A·s)（Ω/s）。

8.2 速度环 PI（对称最优近似）

8.3 MTPA 给定（最大转矩电流比）

id* = ψf2·(Lq − Ld) − √[ ψf2·(Lq − Ld) ]2 + iq2　（适用于 Ld < Lq 的 IPMSM；给定 iq，求使转矩最大的 id*）

9.1 转矩 / 反电势常数

转矩常数：　Kt = 32·p·ψf　[N·m/A]　　（Te = Kt·iq，SPMSM）
反电势系数（相幅值）：　Ke = p·ψf　[V·s/rad]　　（ephase,peak = Ke·ωm；Kt = 1.5·Ke）
线电压有效值反电势：　Eline,rms = √3/2·p·ψf·ωm ≈ 1.225·p·ψf·ωm

9.2 功率与稳态关系

电磁功率：　Pe = Te·ωm = 32·( ud·id + uq·iq )（忽略损耗）
稳态 dq 电压方程（忽略微分项）：　ud = Rs·id − ωe·Lq·iq　　uq = Rs·iq + ωe·( Ld·id + ψf )
相电流幅值：　Is = √id2 + iq2　　id = 0 控制时：us = √( Rs·iq )2 + ωe2·( Lq2·iq2 + ψf2 )

9.3 采样与控制周期经验值

电流环采样周期 Ts = 1/fsw（与 PWM 同步，可双采样双更新）；
电流环带宽 fc ≈ fsw/10 ~ fsw/20；速度环带宽 fsc ≈ fc/10 ~ fc/5；
